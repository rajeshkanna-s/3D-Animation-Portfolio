# 🌟 3D Animation & Interactive Web Portfolio

A collection of cutting-edge, high-performance 3D web experiences, luxury brand landing pages, and interactive animation projects created with modern web technologies (Three.js, React Three Fiber, GSAP, CSS 3D Transforms, Canvas, and Vite/React).

## 🛠️ Tech Stack

- **Frameworks & Libraries**: React, Vite, Three.js, React Three Fiber, GSAP, Lucide Icons, Canvas API
- **Styling**: Vanilla CSS, Glassmorphism, Responsive Grid & Flexbox layouts, Custom CSS Variables
- **Animations**: ScrollTrigger, Smooth Scrolling, 3D Canvas rendering, CSS keyframe animations

## 💻 Getting Started

1. Clone this repository:
   ```bash
   git clone https://github.com/rajeshkanna-s/3D-Animation-Portfolio.git
   ```
2. Navigate into any project directory:
   ```bash
   cd "3D Animation Portfolio/velora-chocolate"
   ```
3. Install dependencies and run development server:
   ```bash
   npm install
   npm run dev
   ```
4. Or open `index.html` at the root to access the central portfolio hub.
